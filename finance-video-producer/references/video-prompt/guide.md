# 整片编写与逐段投模

## 先写整条视频，再拆成生成段

1. **沿整片时间轴写镜头和声音。** 先写清上一幕导致下一幕发生了什么，再按生成入口时长、动作完成点、话轮和剪辑点划分生成段。一个生成段可以含一个或多个镜头，同一个镜头也可能跨多个生成段。整片时间用于衔接与剪辑，每段提交按段内时间从零开始。
2. **从同一份全片分镜写出所有段。** 人物称呼、定妆、场景布局、关键道具和连续音轨沿用同一份记录。为每个段界写清上段末态、下段初态、接法和有意变化。涉及的可见状态至少具体到本次需要延续的对象，例如坐位、手势、物件位置、翻盖进度或光线。待定的后续段记录当前可交接的末态，等后续剧情明确再写接法。
3. **按接法判断哪些状态要接上。** 同一镜头或动作跨段时，两段必须处于同一动作阶段。下一段取上段已采用片段在有效剪入范围内的最后一帧，经已核实的严格首帧入口绑定。明确硬切时，可按故事意图变更时间、光线、景别或桌面内容，仍核对人物、地点等应延续的设定。段界写在已有的 `opening`、`ending`、`seam` 和 `join` 中。
4. **按生成顺序交付逐段投模词。** 每个生成段编号，带本段正文、所需媒体映射和生成参数。实际附件齐备后，仅凭本段的提交内容即可生成。全片跟踪同一项参考素材时用同一素材 ID 和版本。投模正文里的图号从本段实际附件重新编号。若下段依赖实际尾帧，先写计划首态，选到上段样片后再用真实尾帧核对并定稿。

## 在每个生成段内写完整指令

按真实入口编写。全模态参考指出借用哪个媒体中的哪个主体或属性。原视频编辑和延长明确操作对象与变化所在。段落结构随任务复杂度变化。

1. **定义素材和主体。** 按本次实际上传顺序引用图片、视频、音频。说明每份素材负责哪项特征。角色名称首次定义后贯穿全文。没有看到的发型、服装细节等直接引用参考图。有客户原图的产品或界面按原图约束外观、展示面和可见文字。
2. **写出开场可见状态。** 交代本段第一帧的空间、光线、主体位置、关键物件位置和动作是否已经发生。画幅、总长、音轨开关按真实入口配置。续接段使用上段已选片有效尾帧和已核实的首帧输入。
3. **按动作接力写镜头。** 单镜头写明机位、主要运镜和构图落点。串联动作写明谁先做什么、如何接触物件、出现什么可见结果、下一个动作何时接上。真实多镜头按切镜顺序写。确需卡点时可提示大致时间或触发词，精确秒点以剪辑与实片复核为准。
4. **写末帧与具体约束。** 写明画面最终同时要看清什么。约束只覆盖容易拍错且影响本段的细节，例如护盾不得遮脸、保单夹不得浮起。将导演目标改写为可观察的动作或构图。`subjects` 留给分镜摘要，`join` 留给段界和合成清单。段内切镜写进正文，段间剪辑由合成执行。
5. **按声音和文字路线交付。** 模型负责的对白用说话人、实际样音和逐字原句表达。后期旁白在确认单中保留说话人、逐字稿和段内时标。静音底片在正文指定闭口、在请求中关闭音频。后期排字保留需要的画面区域，原字交给剪辑。用户指定按原文投模时逐字保留，并列明发现的冲突。

## 提交前沿整片走读

先用各段实际正文和附件逐段走读，检查参考图号、开场、动作与结束状态。再把每一对相邻段的末态与初态并排读，核对人物和素材版本、空间方向、道具状态、动作进度，以及台词和字幕是否重复、漏接或错位。两段写法冲突或单段返修改变首末状态时，回到整片分镜记录新状态，再核对受影响的相邻段。如果上段实片换版，按新实际有效尾帧复核续接段。硬切的接法和本段输入均能继续使用时，可保留已有样片。

通过 `segment-text` 交付含完整正文和实际输入的确认单，登记 `present_segment` 后等待用户回复。用户采用后仍须按宿主完成本批实际生成确认，提示高消耗；具体消耗预估仅作可选信息，没有数值不额外挂起。真实输入和确认就绪后方可 `claim-video`，实际宿主或工具限制按 [宿主接法](../video-workflow/references/host.md#开拍前检查与失败分支) 执行。局部编辑改用 `repair-text`，交付原片定位和完整编辑指令。
