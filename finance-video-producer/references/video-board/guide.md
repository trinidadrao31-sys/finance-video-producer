# 分镜母版与分段

先读取当前故事草案、台词/画面字表、已知图片或待制图项和 brief.type 命中的主编导逐镜稿。对照观众目标，把已确认的情绪或关系落实到焦点、动作起止和下一个镜头如何接。例如“接住跑来的孩子”应看得见跑近、接触、托住与落定。保留指定拍法与接缝数据。每镜给出时间、职责、主体起点/变化/末态、景别与轴线、光色、谁发声以及分配的原句 ID、可读画面字、素材用途与下镜接法。人物定妆、服装、固定机位和色温给可见特征，不单说“保持上一段”。第 2 步先用待制素材 ID 和用途编排，第 3 步再把选定的实际图绑定到相同位置。若分镜中发现新的必要图项，在同一方案卡补上用途与清单，生成后供用户选用。分镜拼图仅用于评审。不要求每个文字创作补照片。

先沿整片时间排镜和声音，再用所接模型单次时长、完整句尾、动作结束、信息页/章节边界切段。新片超限必须拆，短片也可因不同资产约束拆。共享一份毫秒时间轴，每段从 0 开始，保留时长相加等于用户确认总时长。每段实际请求秒数为上取整且至少达到模型下限，余量只延续末态，裁掉后拼接。若一整句超过单次上限，优先用一条用户确认的连续旁白音轨跨画面（真实具备该路径时），或由用户在故事节点确认可独立朗读的短句。demo 的原生语音模式以一句仅落入一段为约束。

需要自动选剪点时，用宿主的分段计算能力。输入 duration_ms、max_seconds 和 cuts（每个含 at_ms、kind、note）。kind 可为 scene、chapter、sentence、action、page、hold。protected 填完整发声/不能打断的动作，每项含 id、from_ms、to_ms。没有计算工具时沿整片时间排序，圈出不能切断的区间，再从上一个段界向后选择可容纳、且不落在保护区间内的剪点，必要时回退并重新分配各段，核对有效时长总和。例如 36 秒故事在 18 秒一问一答之间落音，把 18000 作为 sentence 剪点，禁止剪在问句区间内部。输出有效局部时长和整秒请求；无可行解时回故事/分镜处理，不能截词。

每段记录 opening、ending、subjects、ambience、shots、cues、titles、asset_ids，以及与上一段接缝的 seam。硬切记录构图承接与落音；动作续接保存上一段有效末帧作下一段真首帧，维持轴线、动作阶段、目光、道具与光位；场景变化选有动机的硬切/遮挡/形状匹配。叠化可在有效段内生成，交接仍在落定后裁切；如另做交叉叠化，须补足双侧素材余量并核算最终片长。持续音乐若要求同源，使用真实连续音轨并记录起止；只有原生逐段音频则留自然落音，不许声称同一音轨。

后续段尚无首帧时，把“实际拿到上一段已选片的有效末帧”登记为依赖，不写假附件。上一段更换时复核相邻段，跟帧段需重绑末帧，独立硬切段可复用。与故事、待制图片和逐段提示词一起展示，沿用本次方案确认。总控事件表列出每段字段。

交付逐段提示词前，对读所有相邻段的 `ending` 与 `opening`。在下段 `join` 写清这一次延续与有意变化，例如同一客厅和定妆，硬切后改为白天及不同桌面物件。为编排留在 `shots` 里的毫秒时间用于整片对齐。提示词内的单镜头连续动作可用“停稳后”“打开后”等可观察的触发条件。

把指定停留或实测语音长度落在对应的 shot、title 或 cue 的 min_duration_ms，并核对真实起止之差。整片秒数合计正确也要复核局部窗口。关键动作在分镜中标出起点与可辨认的完成状态；粗估朗读时间请显式标估时。

首次方案锁定起止和切分依据，第二步核对实际话轮。编号卖点按触发词卡拍，例如从上一段四指先收手；说“第一”时只伸食指、其余收拢，说到“政策好”亮盾牌；“第二，价格优”在原词处切价格图标。只有分镜要求比两指时才伸两指；同一只手比数和指向写清先后。图卡留足辨认时间。
