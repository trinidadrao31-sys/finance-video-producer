# 创作验收

交首稿前从观众的位置顺看一遍。先用一句话记下看完应能做什么、明白什么或感到什么，再指认哪个画面或声音提供了证据。若只有旁白在宣称情绪、分镜反复说明同一点、或几个形容词可以套到任何客户身上，优先重写缺证据的那一镜；成熟原稿和用户指定的拍法继续有效。

| 主拍法 | 怎样在这条作品里看出质量 |
|---|---|
| 情景 | 用人物在具体情境中的动作或选择建立关系变化。在关键前后各找一个可见细节，让观众有机会自己读懂。 |
| 主播 | 听第一句话能知道这件事和谁有关；主要观点有例证或动作承接。按声源试读，给听者留出消化信息的时间。 |
| 图解教学 | 跟着画面真的能完成一次判断或操作。对比对象同时可辨、单位一致；读数与结果有停留。检查是否把必要条件拍成了充分条件。 |
| 活动与品牌发布 | 给观众一个能记住的具体揭晓或品牌动作；业务事实、期限、利益点和参与动作各有来源，没给的留空。 |
| 物体／服务演示 | 让观众亲眼看出动作前后哪里改变，镜位应能证明它。抽象服务可用一次可信的服务行动体现。 |

时间、动作、声音、镜头选择都可随题变化。看不出作品专属的细节时，从已给材料找一个能承担两次不同作用的动作、声音或物件，也可以采用更适合本题的手法。删除不帮助此目标的镜头。创作自检在后台完成，只向客户呈现选定的方案、重要取舍及真实待办。

交导演稿时以稿中可执行证据判断；只有拿到真实视频并检查对应秒点、声音与前后接缝，才给成片结论。客户提出局部修改时，从同版快照复核受影响窗口与相邻接点。

当理解目标需要分辨两个相似对象、核查差异或做选择时，按稿遮掉讲解词走一遍：观众能否指出比的对象、决定性的差异和不同结果？若关键反例只在“后续可选”里，先写进当前可拍动作，使之能用画面验证。只要一个正例即可教会的题目沿用正例即可。
